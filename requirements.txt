# Pinned runtime set.
#
# `pyproject.toml` is the source of truth for dependency *ranges*. This file is
# the pinned set used by `start.sh` and the release workflow, where a
# reproducible bundle matters more than flexibility.
#
# For development prefer:  pip install -e ".[providers,dev]"
# Tooling only:            pip install -r requirements-dev.txt
#
# Removed in Phase 0: `asyncio==3.4.3` (asyncio is in the standard library; the
# PyPI package of that name is a 2015 backport that shadows it), plus duplicate
# pins for rich, click and typer.
#
# Regenerated in Phase 1 from the environment the test suite actually runs in.
# The previous set had been unsatisfiable since datapizza-ai was adopted —
# pydantic was pinned to 2.7.1 while datapizza-ai-core requires >= 2.10.5 — so
# `pip install -r requirements.txt` failed on a clean machine and nobody
# noticed, because every developer had an environment built from pyproject.
# The container build is what found it, which is an argument for the container
# build being part of CI.

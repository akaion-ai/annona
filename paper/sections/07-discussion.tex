\section{Limitations and future work}
\label{sec:discussion}

\paragraph{Trust in the ledger writer.} The audit checks that the recorded decisions are the
ones the policy prescribes, but it cannot check that the records are true. A component that
misbehaves and records its decisions consistently will pass. Computing labels independently of
the controls they describe (\cref{sec:eval-compliance}) limits what an accidental defect can
hide. A deliberate one can only be excluded by attesting the code that writes the ledger, for
example through measured boot of the host and attestation evidence recorded with each placement.

\paragraph{The classifier.} \Cref{prop:leak} reduces the leak rate to two quantities: how often
material is stored where the policy does not expect it, and how often the classifier misses
it. In E2 the classifier's miss rate is fixed by construction. The next step is a trained
classifier with a threshold fitted on labelled documents, evaluated also against inputs written
to appear harmless. The assumption that misfiling and misclassification are independent needs
to be tested.

\paragraph{Declassification.} Briefs and redaction release material by design. We reclassify
their output and support a list of sealed material, but we do not prove that a brief of
restricted material only contains what its new class allows. Permissive information-flow
analysis~\citep{siddiqui2024permissive} is one possible approach.

\paragraph{Undeclared tool channels.} The network ceiling covers tools that the policy knows
to reach the network. A tool whose code sends data through a channel it does not declare is
outside our threat model; sandboxing the tools would complement \annona.

\paragraph{Scripted adversary.} In E2 to E4 the agent always attempts the most damaging
sequence available with its tools. This bounds what a model could do with the same tools, but
the adversary does not adapt. E5 uses real models under AgentDojo's attacks, while adaptive
attacks against the classifier remain to be evaluated.

\section{Conclusion}

The location where each agent step runs is a security decision that is taken many times a day.
\annona{} makes this decision for every step using a default-deny policy over a class that only
increases, holds steps that cannot be placed, treats network tools as substrates, and records
each decision so that it can be checked using only the ledger and the policy. In our
measurements with canaries that no policy lists, the perimeter leaks only the documents its
classifier misses, and a calibrated classifier turns that miss rate into a parameter chosen by
the operator. The system, the evaluation harness and all results are released as open source.
